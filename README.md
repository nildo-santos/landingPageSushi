# Landing Page Sushi — Estudos de GSAP

## Demonstração

https://github.com/user-attachments/assets/57cfb68f-9430-498b-b2d0-56e5922492bf



Este projeto é um exercício de estudo da biblioteca **GSAP (GreenSock Animation Platform)**, desenvolvido com HTML, CSS e JavaScript.

O objetivo é praticar a criação e a sincronização de animações em uma landing page de um restaurante de sushi. O projeto tem finalidade educacional.

## Animações

- Entrada cinematográfica com transição do escuro e zoom suave.
- Letras do título aparecendo uma por vez.
- Reflexo no título, feito com CSS e iniciado pela sequência do GSAP.
- Rotação lenta e contínua do prato.
- Contador da avaliação até 4.9.
- Entrada sincronizada dos textos, botões e navegação.

## Conceitos praticados

- Sequências com `gsap.timeline()` e marcadores de tempo.
- Animações com `gsap.from()` e `gsap.to()`.
- Entrada sequencial com `stagger`.
- Controle de duração, suavização (`ease`) e repetição.
- Respeito à preferência por movimento reduzido.

## Como visualizar

Abra `index.html` no navegador ou utilize a extensão Live Server do VS Code.
